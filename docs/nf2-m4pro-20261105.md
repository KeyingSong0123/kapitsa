## 检查与边界

- 历史记录：两个模型各 584 行 target logits 逐位相同；新核的小尺寸 shader validation / debug layer 检查及真实系数检查通过。9B 目标预打包增加约 3.96 GiB，27B 完整覆盖增加约 12.75 GiB，另有加载时打包成本。
- 9B 草稿侧 NF2 未测到超出波动的额外收益，NF1 更慢；8K / 16K 和原生 MTP 没有完整有效性能结论。27B API 的 keepalive 时序检查在 A、B 均失败。结果不外推到其他 Mac、精度或上下文。
- 标准 `kapitsa bench` 会清除实验开关，其结果不能证明本表的 NF2 收益。本表来自保留在本机的实验 A/B 请求记录。
- 本次发布前：Release 构建、37 项 CPU 检查、独立 packed codec 检查（267,378 对系数）和全部 7 项 `prek` 检查通过；未加载模型或重跑 GPU。
